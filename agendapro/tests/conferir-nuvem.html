Conferir o projeto no Supabase

Bate na API do seu projeto do jeito que um estranho na internet bateria: só com a chave pública, sem login nenhum.

Esta página não guarda nem envia nada para lugar nenhum: ela fala direto do seu navegador com o seu projeto. A chave publicável pode ficar à vista — é pública por natureza, e quem protege os dados é o RLS. A Secret key (sb_secret_…, o antigo service_role) não deve ser colada aqui: ela passa por cima de todo o RLS, e os testes abaixo passariam sem provar nada.
